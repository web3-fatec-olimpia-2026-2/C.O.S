# ADR 002 — Uso de `TextChoices` para campos de opções restritas

## Contexto
O model `OrdemServico` possui campos que só podem aceitar valores predefinidos, como `categoria`, `status` e `prioridade` e precisávamos de uma forma segura de restringir as opções na base de dados.

## Decisão
Decidimos utilizar a classe `models.TextChoices` acoplada ao parâmetro `choices` de um `models.CharField`. As opções (como `ABERTA`, `EM_EXECUCAO`) foram definidas dentro da própria classe `OrdemServico`.

## Alternativa descartada
Utilizar as tradicionais tuplas de opções globais (ex: `STATUS_CHOICES = (('ABERTA', 'Aberta'), ...)`). Descartado porque as tuplas tradicionais não oferecem autocompletar no editor de código e deixam as constantes espalhadas. O `TextChoices` encapsula os valores dentro do modelo de forma orientada a objetos (permitindo usar `OrdemServico.Status.ABERTA` no código).

## Consequência
O código fica mais legível e protegido contra erros de digitação ao longo do projeto. Em contrapartida, a declaração inicial do model fica mais longa.
