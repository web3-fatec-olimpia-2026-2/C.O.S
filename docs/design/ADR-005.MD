# ADR 005 — Construção de Interface Própria e Segura para Autenticação

## Contexto
O ponto de entrada do sistema necessitava de uma identidade visual clara e profissional. A utilização de formulários genéricos ou do painel de administração nativo do Django não oferecia a experiência de usuário (UX) desejada, nem permitia a aplicação rigorosa de regras de segurança visual no Front-end (como impedir o preenchimento automático de credenciais em dispositivos compartilhados).

## Decisão
Decidimos construir templates HTML customizados (`login.html` e `home.html` com botão de logout explícito), estruturados com Flexbox para centralização e classes CSS próprias (`.login-container`, `.form-group`). Aplicamos tags semânticas (`<label>`) para acessibilidade e forçamos os atributos `autocomplete="off"` e `autocorrect="off"` nos campos de *username* e *password*.

## Alternativa descartada
Utilizar o template de login padrão do Django Admin ou depender exclusivamente de bibliotecas externas (como o Bootstrap) para gerar o formulário de imediato. Esta alternativa foi descartada porque não nos daria o controle fino sobre o comportamento dos campos (segurança contra preenchimento automático) nem garantiria o alinhamento total com a identidade visual planejada para a aplicação.

## Consequência
O sistema ganha uma porta de entrada coesa, moderna e segura, com uma separação clara das áreas de cabeçalho, conteúdo e ações. A manutenção das classes CSS (como `.btn-login` e `.form-input`) passa a ser responsabilidade da equipe de Front-end, o que exige maior atenção manual, mas garante total controle sobre a acessibilidade e a estética.
