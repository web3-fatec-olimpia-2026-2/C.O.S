# ADR 006 — Feedback Visual Integrado para Erros de Autenticação

## Contexto
Quando um usuário insere credenciais incorretas, o sistema não pode simplesmente recarregar a página sem explicação, sob pena de causar frustração e confusão. Era necessário um mecanismo claro para informar o usuário sobre o erro.

## Decisão
Implementamos o bloco condicional `{% if messages %}` diretamente no template de login, desenhando uma caixa de mensagem (`.error-message`) com fundo avermelhado e ícone de aviso (`.error-icon`). Esta caixa permanece oculta em situações normais e surge com uma animação suave apenas quando o servidor retorna um erro de autenticação.

## Alternativa descartada
Utilizar alertas nativos do navegador (`alert()` em JavaScript) ou redirecionar o usuário para uma página separada com a indicação de erro. Descartado porque quebra a fluidez da navegação e resulta em uma experiência de usuário obstrutiva e pouco profissional.

## Consequência
O usuário recebe feedback imediato e amigável sem sair da tela de login. Esse padrão de mensagens de erro estabelece uma convenção reutilizável para o resto do sistema, embora adicione uma leve complexidade condicional ao arquivo HTML.
