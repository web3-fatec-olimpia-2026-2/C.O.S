# ADR 007 — Estratégia de Responsividade Nativa (Mobile-First)

## Contexto
O sistema será acessado tanto por administradores em computadores quanto por prestadores de serviço em campo através de celulares. Interfaces estáticas ou baseadas em pixels fixos quebram a usabilidade, gerando barras de rolagem horizontais em telas pequenas.

## Decisão
Adotamos uma estratégia de responsividade utilizando a meta tag viewport no HTML, medidas relativas no CSS (`rem` e `%`) e a aplicação de media queries (`@media (max-width: 480px)`) para reajustar fontes, espaçamentos e a largura da caixa do formulário em dispositivos móveis.

## Alternativa descartada
Desenvolver duas interfaces separadas (uma para desktop e outra para mobile) ou importar um framework CSS pesado apenas para o sistema de grid. Descartado porque duplicaria o esforço de manutenção do código HTML e introduziria código desnecessário para uma interface que, nesta fase inicial, é simples e direta.

## Consequência
A interface se adapta perfeitamente a qualquer tamanho de tela, garantindo que o botão e os campos de texto permaneçam utilizáveis em um celular. O custo associado é a necessidade de testar rigorosamente o CSS customizado em várias resoluções durante o desenvolvimento.
