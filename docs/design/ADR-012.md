
# ADR-012 – Implementação e Configuração do PostgreSQL

**Status:** Implementado  
**Data:** 06/11/2026  
**Projeto:** C.O.S. – Controle de Ordens de Serviço

## 1. Contexto

Inicialmente, o projeto C.O.S. utilizava o SQLite como sistema de gerenciamento de banco de dados.

Com o avanço do desenvolvimento e visando melhorar a estrutura da aplicação, foi identificada a necessidade de utilizar um sistema gerenciador de banco de dados mais robusto, adequado ao desenvolvimento colaborativo e à evolução do sistema.

Dessa forma, foi proposta a substituição do SQLite pelo PostgreSQL, mantendo a integração com o framework Django.

## 2. Decisão

Foi definida a adoção do PostgreSQL como sistema oficial de gerenciamento de banco de dados do projeto C.O.S.

A escolha considera sua confiabilidade, suporte a operações relacionais, integridade dos dados, recursos de gerenciamento e integração com o Django.

## 3. Implementação

Foram realizadas as seguintes etapas:

- Instalação do PostgreSQL no ambiente Ubuntu, utilizando WSL.
- Instalação e configuração do PostgreSQL versão 14.24.
- Inicialização e verificação do serviço PostgreSQL.
- Verificação do cluster `14 main`.
- Configuração do banco de dados `cos_db`.
- Configuração da aplicação Django para utilizar o PostgreSQL em substituição ao SQLite.
- Configuração da conexão utilizando a porta padrão `5432`.
- Verificação da comunicação entre o Django e o PostgreSQL.

## 6. Consequências

A adoção do PostgreSQL estabelece uma estrutura de banco de dados mais adequada à evolução do projeto.

**Benefícios esperados:**

- Maior robustez no gerenciamento dos dados.
- Melhor suporte a operações simultâneas.
- Recursos avançados de integridade e consistência.
- Maior adequação para ambientes de produção.
- Facilidade de evolução e manutenção da aplicação.

**Pontos de atenção:**

- Os integrantes da equipe deverão possuir o PostgreSQL configurado em seus ambientes de desenvolvimento.
- As credenciais e configurações de conexão deverão ser mantidas de forma segura.
- As futuras alterações na estrutura do banco deverão ser controladas pelas migrations do Django.
- A equipe deverá manter a compatibilidade entre os ambientes de desenvolvimento.
